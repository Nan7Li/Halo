## 0. 準備

| 需要 | 說明 |
| --- | --- |
| NAS 或小主機 | Debian 13、x86_64（J3160、N5105 等）。一鍵安裝只支援這個組合，其他系統請用 Docker（見 [NAS-J3160.zh-CN.md](NAS-J3160.zh-CN.md)）。 |
| 至少一條線路 | Quectel EC20 / EC25、移動 ML307 等模組（走 VoWiFi），大疆 QDC507 模組（走蜂窩語音），SIM 讀卡器（走 IMS），或一支裝了 AirSIM 的安卓手機。 |
| SIM 卡 | 你自己的、有權使用的 SIM 卡。 |
| 網路 | NAS 能上網，安裝時要能連到 GitHub。 |

先讀一遍 [LICENSE](../LICENSE)。Halo 的核心建立在 VoCat 之上，整體適用 VoCat 的授權：只能用於非商業的研究、教育和個人硬體開發，並有地區和 SIM 卡使用上的限制。

## 1. 安裝

在 NAS 的終端機執行：

```bash
sudo bash -o pipefail -c 'apt-get update && apt-get install -y curl ca-certificates && curl -fsSL https://raw.githubusercontent.com/Nan7Li/Halo/halo/scripts/deploy-cellbridge-nas.sh | bash'
```

安裝程式會：

1. 下載最新的正式版，校驗 SHA-256。
2. 安裝 `alsa-utils`、`adb`、`pcscd` 等依賴。
3. 下載並校驗大疆 QDC507 的語音運行檔，放到 `/opt/halo/qdc507`。
4. 第一次安裝時，請你在終端機輸入管理員密碼（不會顯示在畫面上）。已有管理員就不會再問。
5. 啟動 `halo` 服務。

想先確認這台機器能不能裝，可以把最後的 `| bash` 換成 `| bash -s -- --check-only`，只檢查不安裝。

資料都在 `/opt/halo/data/halo.db`，更新時會保留。

## 2. 第一次登入

瀏覽器打開 `http://NAS的IP:7575`，用剛才設定的管理員密碼登入。

建議先到「设置」看一下：

- 「外观」：深淺色、強調色、玻璃透明度、動畫強度，看自己喜好調。
- 「系统与更新」：確認版本，決定要不要自動更新（預設每 6 小時檢查，沒有通話時才安裝）。
- 「账户与登录」：改密碼，或設定 SSO 和 API Token。

手機上也可以直接用瀏覽器打開，介面會自動變成底部分頁的手機版。iPhone 的 Safari 可以「加入主畫面」，會用 Halo 的圖示。

## 3. 開啟 HTTPS（瀏覽器通話必需）

瀏覽器只在 HTTPS（或 `localhost`）下才允許使用麥克風。用 `http://` 打開時，通話只能聽、不能說。

到「设置」→「网络访问」，開啟「本机自签 HTTPS」。內網用 Halo 的自簽憑證即可，第一次打開時瀏覽器會警告，確認後就能用。如果你已經有網域和反向代理，也可以讓反向代理處理 HTTPS。

## 4. 接上模組

1. 把模組插上 NAS 的 USB。
2. 打開「设备」，Halo 通常會自動發現。沒出現的話點右上角的重新掃描，或手動「添加设备」。
3. 點進裝置，「概览」會顯示 SIM、訊號、網路狀態。
4. 要用 VoWiFi（Wi-Fi Calling）打電話：在裝置頁開啟「VoWiFi」，等狀態列的 SIM → Access → Tunnel → IMS → SMS 都變綠。
5. 「卡策略」可以依 ICCID 設定每張卡要不要自動開 VoWiFi、要不要開飛航模式。

模組的 AT 終端、USSD、eSIM、鎖頻等進階功能也都在裝置頁的分頁裡。

## 5. 打電話、接電話

打開「电话」：

- **撥號**：在「拨号键盘」輸入號碼，上方可以選要用哪條線路，按綠色按鈕撥出。長按 `0` 輸入 `+`。
- **接聽**：不管在哪一頁，有來電時頂部都會跳出橫幅，按接聽就進入全螢幕通話畫面。
- **通話中**：可以靜音、開鍵盤、掛斷；畫面會顯示音訊連線狀態。
- **最近通话**：未接來電標紅，點一下回撥，點 ⓘ 看詳情、播放或下載錄音。

如果畫面提示「只能听，不能说」，回到第 3 步開啟 HTTPS，或在瀏覽器網址列允許麥克風。

## 6. 簡訊

打開「信息」：

- 左邊是對話列表，可以搜尋、左滑刪除或標為已讀。
- 右上角可以寫新簡訊，或把簡訊匯出成 JSON / 離線 HTML。
- 簡訊會透過 VoWiFi（IMS）或行動網路收發，視線路狀態而定。

## 7. 大疆 QDC507 蜂窩語音（CellBridge）

> 這個功能還沒在真實模組上完成驗證，請預期會遇到問題。

1. 確認安裝時語音運行檔有下載成功：`/opt/halo/qdc507` 裡要有三個檔案。
2. 在 NAS 上執行只讀檢查工具（不會改動任何東西），記下模組的聲卡名稱：
   ```bash
   curl -fsSL https://raw.githubusercontent.com/Nan7Li/Halo/halo/scripts/check-cellbridge-nas.sh | bash
   ```
3. 到「设置」→「通话桥」（「电话」頁也有同一個設定入口）：
   - 開啟「启用大疆通话音频」，在「蜂窝音频设备」選你的大疆模組。
   - 開啟「允许初始化匹配的 QDC507 音频」，讓 Halo 把語音模組推到模組上並載入。剛開機的模組一定要開。
   - 點「显示高级设置」：
     - 「模块运行文件目录」填 `/opt/halo/qdc507`。
     - 「ADB 服务地址」填 `tcp:localhost:5038`。
     - 「ALSA 录音设备」和「ALSA 播放设备」照檢查工具列出的模組聲卡填。`plughw:1,0` 只是佔位，不一定是你的模組。
4. 回到「电话」，選大疆那條線路撥出測試。

## 8. 用 SIP 軟電話打

1. 「设置」→「通话桥」開啟「启用 SIP 服务」，在「通话线路」選要用的線路，設定「SIP 账号」和「SIP 密码」。「Halo 连接地址」填手機連得到的 NAS 位址（區網、WireGuard 或 Tailscale IP）。
2. SIP 預設 UDP `5060`，RTP 預設 UDP `40000`。
3. 在手機的 SIP App（例如 Linphone、Groundwire）新增帳號：伺服器填 NAS 的區網 IP 或 VPN 位址，帳號密碼照上面填。
4. 只支援 UDP。從外面連要走 VPN（Tailscale、WireGuard 或下面的 VPS 中繼），HTTPS 反向代理沒辦法轉 SIP。

## 9. iPhone 聽筒（AirSIM iOS App）

這個模式讓 Halo 扮演 AirSIM 的「安卓手機」，iPhone 上的 AirSIM App 就是聽筒，打出去用的是 Halo 上的線路。

1. iPhone 安裝 AirSIM（TestFlight 版即可）。
2. Halo 打開「iPhone 听筒」，開啟「允许 iPhone 连接」。Halo 會監聽三個 TCP 埠：配對 7590、控制 7592、音訊 7593。
3. 「线路」列出 iPhone 上會看到的「SIM 卡」。只有現在能通話、有音訊的線路才會列出；空的話回去確認模組 VoWiFi 或大疆音訊。
4. 點「开始配对 iPhone」，畫面會出現 6 位數配對碼，兩分鐘內有效，輸錯 5 次作廢。
5. iPhone 的 AirSIM 選「配對安卓手機」→「私網 IP」，填 NAS 的位址、配對埠 `7590` 和配對碼。
6. 配對成功後，「已配对的 iPhone」會出現這台 iPhone，就可以用它撥號、接聽、收發簡訊。

注意：本地模式下，AirSIM 要開在前景才收得到來電；也還不支援通話中按鍵（DTMF）。

## 10. 從外面連回家

iPhone 離開家裡的 Wi-Fi 後，要有辦法連到 NAS。挑一種：

### A. VPS 中繼（家裡沒有公網 IP 時推薦）

Halo 主動連到你的 VPS，iPhone 再透過 VPS 連回 Halo。

1. 「iPhone 听筒」→「远程连接（VPS 中继）」→「设置 VPS 中继」。
2. 填 VPS 的 IP 或網域。UDP 埠預設 `51820`，隧道網段預設 `10.8.0.0/24`（VPS 是 `.1`，NAS 是 `.2`），不要跟家裡或 VPS 的區網重疊。
3. 按「连接并生成脚本」。Halo 會產生金鑰、建立隧道，並給你一份「VPS 安装脚本」。
4. 到雲端廠商的安全組放行這個 UDP 埠。
5. 把腳本存到 VPS，用 root 執行：`bash halo-relay.sh`。腳本可以重複執行。
6. Halo 上 VPS 那一行從「等待 VPS」變成「已连接」就成功了。

iPhone 怎麼連過去，有兩種做法：

- **用你 VPS 上已有的代理節點（推薦）**：
  1. 在小火箭（Shadowrocket）加一條規則：`IP-CIDR,10.8.0.0/24,你的VPS節點`，放在最上面。
  2. 把小火箭設定裡 `skip-proxy` 和 `tun-excluded-routes` 中的 `10.0.0.0/8` 刪掉，不然流量不會進小火箭。
  3. VPS 上的代理服務端不能封鎖私網位址。很多 Xray、sing-box 範本預設把 `geoip:private` 導到 block，要拿掉。
  4. AirSIM 選「私網 IP」，填 `10.8.0.2`、埠 `7590`。
- **直接用 WireGuard**：在「WireGuard 设备」點「添加设备」，把產生的設定檔匯入 WireGuard App，或照著填到小火箭的 WireGuard 節點。新增或刪除裝置後要在 VPS 上重跑一次腳本。

iOS 同一時間只能開一個 VPN，所以如果平常就開著小火箭，建議用代理節點的做法。

### B. Tailscale

NAS 和 iPhone 都裝 Tailscale、登入同一個帳號。AirSIM 用「私網 IP」填 NAS 的 Tailscale 位址（`100.x.x.x`）即可。Halo 預設就允許 Tailscale 位址連線。

### C. AirSIM 雲端模式

在「iPhone 听筒」開啟「云端（AirSIM Relay）」。iPhone 在 AirSIM 配對時不要選「純本地」，配對後在 App 裡打開「雲端模式」。

好處是任何網路都能用，App 不在前景也會響鈴；代價是通話語音和簡訊會經過 AirSIM 作者的 Relay 伺服器。這個模式還沒在真實 Relay 上驗證過。

### D. 公網網域

如果家裡有公網 IP、也有網域，可以在路由器轉發三個 TCP 埠，並在「iPhone 听筒」的「证书」填入系統信任的憑證（例如 acme.sh 簽發的）。AirSIM 的「公網網域」模式不接受 Halo 的自簽憑證。

> Cloudflare Tunnel 只能轉 HTTP，AirSIM 的音訊是原始 TCP，透過 Tunnel 會變成撥得通但沒有聲音。

## 11. 安卓手機當線路

手邊有閒置的安卓手機，可以把它變成 Halo 的一條線路：

1. 手機安裝 AirSIM Standalone APK，設為預設電話應用，並在 Shizuku 裡授權。
2. 手機和 NAS 要在同一個區網，或在同一個 Tailscale 網路裡。
3. 手機上打開「一次性配對」，記下 IP、配對埠和 6 位數配對碼。
4. Halo 打開「安卓手机」→「配对安卓手机」，填入上面的資料。

配對後就能用這支手機打電話、接電話、收發簡訊，聲音在瀏覽器裡聽說。注意：本地模式配對會覆蓋那支手機原本的 AirSIM 雲端設定。

## 12. 通知、網路與其他設定

- **通知**：「设置」→「通知」可以把新簡訊和來電推送到 Telegram、Bark、Email、Pushplus、Webhook、企業微信、飛書和 MeoW。
- **網路**：「网络」頁有三個分頁：
  - 「代理」：讓模組的 VoWiFi 流量走上游 SOCKS。
  - 「导出代理」：把模組的行動網路分享成代理。
  - 「WireGuard」：管理隧道。VPS 中繼建立的 `halovps` 隧道也會出現在這裡。
- **自动任务**：排程發送簡訊，或撥打電話並自動掛斷（適合保號）。
- **实时日志**：排查問題時看這裡；「设置」最下方的「下载脱敏诊断包」可以匯出不含敏感資料的診斷包。

## 13. 更新與備份

- 自動更新：「设置」→「系统与更新」。更新前會自動備份資料庫，保留舊版程式；更新後要重新登入。
- 手動更新：同一頁按「检查更新」和「应用更新」。
- 備份：停掉服務後，複製整個 `/opt/halo/data` 目錄。
- 重新安裝：再跑一次安裝指令即可，帳號和資料會保留。

## 14. 常見問題

**通話只能聽不能說**
瀏覽器拿不到麥克風。用 HTTPS 打開 Halo，並在網址列允許麥克風（第 3 步）。

**「QDC507 card0 不匹配」或「card0 尚未注册」**
剛開機的大疆模組要先載入語音模組才會有聲卡。確認「通话桥」裡開了「允许初始化匹配的 QDC507 音频」。仍然失敗的話，錯誤訊息會附上模組實際的聲卡清單，請回報。

**VPS 中繼一直「等待 VPS」**
依序檢查：VPS 安全組有沒有放行 UDP 埠、腳本有沒有在 VPS 上跑成功（最後會印出 `wg show halo`）、VPS 位址有沒有填錯。

**iPhone 配對失敗**
配對碼兩分鐘內有效，輸錯 5 次就要重新開始配對。從外面配對時，確認 iPhone 能連到 NAS 的位址（試試在 Safari 打開 `http://位址:7590`）。

**小火箭開著時 AirSIM 連不上**
多半是 `skip-proxy` 或 `tun-excluded-routes` 排除了 `10.0.0.0/8`，見第 10 步。

**電話「还没有电话线路」**
回到「设备」確認模組的 VoWiFi 已就緒，或設定大疆通話橋、安卓手機線路。

還有問題或發現 bug，請聯絡維護者，附上「设置」最下方「下载脱敏诊断包」下載的檔案，會更快找到原因。
